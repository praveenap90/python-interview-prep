🔍 EDA Checklist

  • Shape & dtypes: df.shape, df.dtypes
  • Missing: df.isnull().mean()
  • Duplicates: df.duplicated().sum()
  • Univariate: df.describe(), value_counts()
  • Bivariate: groupby(), corr()
  • Outliers: IQR bounds or z-score

🧹 Missing Value Strategy

Column typeTypical fix
NumericMedian fill
CategoricalExplicit "unknown" label
Primary keyDrop the row
High missing %Consider dropping column

🧬 Encoding Decision Guide

SituationMethod
Low cardinality, no orderOne-hot
Has real orderOrdinal / label
High cardinalityFrequency / target encode
Continuous → groupsBinning (pd.cut)

⚠️ Common Interview Traps

ScenarioCorrect instinct
"ModuleNotFoundError" despite package installedCheck the selected interpreter, not the package
Fill value computed on train+test combinedData leakage — fit only on train
Mean looks "off" for a skewed columnCheck the median instead
One-hot encoding a column with 5,000 categoriesUse frequency/target encoding instead
A model "works great" using a feature from the futureSuspect feature leakage
